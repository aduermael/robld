robld

Roblox Studio Interface for Agents

Ultimate tooling for your agent (Claude Code, Codex, Grok Build, etc.) to work on Roblox games like a pro.

CLI: robld · pronounced robuild

Prerequisites

Roblox Studio should be installed.

Install

Copy this prompt into Claude Code, Codex, Grok Build, Cursor, or any coding agent. That is the whole install.

INSTALL_PROMPT_PLACEHOLDER

What it does

  1. Installs robld — the command-line interface your agent uses to work efficiently with Roblox Studio.
  2. Your agent calls robld --install once to install the skill.
  3. That's it. Start prompting your agent to create or work on a game in the current folder.
