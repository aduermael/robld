Install

Copy this prompt into Claude Code, Codex, Grok Build, Cursor, or any coding agent. That is the whole install.

Install robld (Robuild — agent-first Roblox CLI) on this machine, then set up this project folder.

1. Detect OS and CPU arch.
2. Download the matching binary from the latest GitHub release of https://github.com/aduermael/robld
   Asset names:
   - robld-darwin-arm64
   - robld-darwin-amd64
   - robld-linux-arm64
   - robld-linux-amd64
   - robld-windows-amd64.exe
   Use: https://github.com/aduermael/robld/releases/latest/download/
3. Install it on PATH in the usual place for this OS:
   - macOS / Linux: ~/.local/bin/robld (create the dir if needed; chmod +x)
   - Windows: %LOCALAPPDATA%\Programs\robld\robld.exe and ensure that folder is on PATH
4. From this project folder, run: robld --install
5. Confirm `robld` works (`robld --help`) and that skill files exist under .claude/skills/robld, .grok/skills/robld, .agents/skills/robld, .cursor/skills/robld, and .codex/skills/robld.

Do not ask me to run these steps by hand unless a permission dialog needs a human. Prefer the release binary over building from source.

What that does

  1. Puts robld on your PATH from the latest release.
  2. robld --install drops the Roblox skill into this folder for the common agents.
  3. Then: robld --new "My Game" and re-run robld until it prints READY.
